# Hypertext Transfer Protocol (HTTP)

The Hypertext Transfer Protocol (HTTP) is an application-layer protocol for
transmitting hypermedia documents, such as HTML. It was designed for
communication between web browsers and web servers, and follows a classic
client-server model.

HTTP was initiated by Tim Berners-Lee at CERN in 1989. The first documented
version, HTTP/0.9, dated to 1991 and supported only the GET method. HTTP/1.1
was standardized in 1997 and remained dominant for nearly two decades. HTTP/2,
published in 2015, introduced multiplexing over a single connection. HTTP/3,
standardized in 2022, runs over QUIC instead of TCP.

HTTP is a stateless protocol: the server does not retain session state between
requests. Cookies are commonly used to add stateful behavior on top of it.
